#### 가상돔을 기반으로 렌더링하기

- [x] createVNode 함수를 이용하여 vNode를 만든다.
- [x] normalizeVNode 함수를 이용하여 vNode를 정규화한다.
- [x] createElement 함수를 이용하여 vNode를 실제 DOM으로 만든다.
- [x] 결과적으로, JSX를 실제 DOM으로 변환할 수 있도록 만들었다.

#### 이벤트 위임

- [x] 노드를 생성할 때 이벤트를 직접 등록하는게 아니라 이벤트 위임 방식으로 등록해야 한다
- [x] 동적으로 추가된 요소에도 이벤트가 정상적으로 작동해야 한다
- [x] 이벤트 핸들러가 제거되면 더 이상 호출되지 않아야 한다

- [x] 요소의 타입이 변경되었을 때 새로운 요소를 생성해야 한다

## 과제 셀프회고

이번 2주차 과제는 1주차보다 조금 더 힘든점이 있었습니다.
normalizeVNode를 구현하며, 다양한 타입으로 들어오는 vNode를 정규화를 시키는 코드를 작성하는데, 여러 깊이로 들어오는 vNode를 디버깅하는 과정에서 많은 시간을 들였습니다.

또한 eventManager에서 초기에는 $el과 eventType을 한 Map으로 관리하고, $el과 handler를 다른 Map으로 관리하여 호출하고 있었습니다.
하지만 해당 과정으로 구현하였을때, 페이지 이동간에 한 이벤트에 대해 여러 요소가 등록되지 않아 새로고침이 발생하였습니다.
처음 작성한 코드의 구조를 바꾸기 위해 여러 방법을 시도했고, 하나의 Map을 생성하고, 내부에 new Map을 만드는 식으로 변경하여 하나의 이벤트 타입에 대해 여러 요소들을 추가하여 페이지 이동간에 새로고침을 막을 수 있었습니다.

### 기술적 성장

- DocumentFragment을 어떤 상황에서 사용할 수 있는지 배웠습니다.
- Object.entries() 와 Object.fromEntries()을 학습하였습니다.
- VirtualDom을 통해 이벤트를 할당하고 관리하는 과정을 통해 VirtualDom이 수행하는 동작을 이해하였습니다.
- VirtualDom을 실제 돔으로 구현하고, updateElemnt를 통해 변경된 요소만 변경할 수 있게 구현하여 불필요한 렌더링을 최적화시켰습니다.

### 학습 효과 분석

이번 과제를 진행하며, 다른 분들의 코드에서 도움을 많이 받았습니다.
혼자 고민하는 과정을 좋게 생각하지만, 다른 분들이 작성한 좋은 코드를 이해해고, 작성하는것도 좋은 학습이라고 생각하게 되었습니다.

### 과제 피드백

일단 과제 코드이외의 코드를 온전히 이해하지 못한것이 아쉽습니다.
과제에서 요구하는 virtualDom을 구현하고, 이벤트를 관리하는 것도 물론 중요하지만 해당 코드를 잘 동작시키게끔 기반이 되는 코드를 더 이해했다면, 해당 과제에 대한 전반적인 흐름을 더 쉽게 캐치할 수 있지 않았을까 생각이 듭니다.
